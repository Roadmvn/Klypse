# Security Policy

## Supported versions

The latest published Klypse release receives security fixes. Older development snapshots are not supported.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue, especially if it could expose captured images, recordings, clipboard data, or local files.

Use GitHub's private **Report a vulnerability** form in the repository's **Security** tab. If that form is unavailable, email the maintainer at [roadmvn@outlook.fr](mailto:roadmvn@outlook.fr) before sharing technical details.

Include the affected version, Linux distribution and desktop session, reproduction steps, and the expected impact. Remove personal capture contents, credentials, and unrelated system information from logs before attaching them.
